# 配套技能

[background-terminal](SKILL.md) 为 DSH Agent 提供持久终端的操作流程，覆盖 Electron 构建与热更新、长程编译、本地进程和需要观察进度的大文件下载。

## 发现与加载

插件挂载时，[技能加载器](../../lib/bundled-skill.mjs) 读取随包技能，并在宿主提供 `skills` 服务时通过 `skills.register` 注册。模型先看到技能名称与 `description`，选中后才加载正文。

同一作用层内，项目技能优先于运行时技能，运行时技能优先于用户目录技能；不同作用层按宿主的就近规则选择。同名副本的实际来源应通过按名加载后的 `provider`、`resourceBase` 与正文确认。

技能在插件挂载期读取；修改后需要重新挂载插件，是否重启以宿主应用结果为准。缺少 `skills` 服务时，工具仍可使用，配套技能注册会被跳过。
